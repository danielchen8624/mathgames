# Number Forge

A Next.js mental-math game based on the classic “24” puzzle. Players combine four numbers with addition, subtraction, multiplication, and division to reach a chosen target.

## Features

- Five difficulty levels with increasingly wide number ranges and trickier solution paths
- Targets 24, 36, 72, 73, or any custom value from 1–999
- Exact rational arithmetic, including fractions and negative intermediate values
- “No solution” rounds at Expert and Brutal levels
- Undo, solution reveal, keyboard operators, responsive layout, and saved local stats

## Run locally

Install dependencies and start the Next.js development server:

```sh
npm install
npm run dev
```
